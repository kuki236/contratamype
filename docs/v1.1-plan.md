## 2. Decisiones de producto

- La web/API y el dashboard muestran **Todos (2024–2025)** por defecto, con filtro de año explícito.

- El dashboard usa un selector de año; no se recalcula MYPE ni se duplica la búsqueda de la web.
- El explicador sigue siendo plantilla; el adaptador Gemini es opcional y usará `GEMINI_API_KEY` desde `.env`.
